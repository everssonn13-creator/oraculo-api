# Como alimentar a base de conhecimento

Todo arquivo `.md` ou `.txt` colocado nesta pasta entra na base do Oráculo do Saneamento
(este arquivo `leia-me` é ignorado). O título do documento é a primeira linha iniciada por `# `.

Boas práticas:
- Um assunto por arquivo (ex.: `sinisa-2024-nordeste.md`, `catalogo-centrifugas-fabricante-x.md`).
- Sempre cite a fonte e a data dos dados no próprio texto.
- Tabelas podem ser coladas em texto/markdown; a IA lê os trechos mais relevantes para cada pergunta.

Também é possível enviar PDFs, TXT, MD e CSV pela própria plataforma (botão "Base de conhecimento").
